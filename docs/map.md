# Waykit map

Skills, SOPs, MCP servers, evals, and philosophy sections are derived from the kit tree, not a second catalog. The same index feeds kit-knowledge, so an agent can fetch one node instead of the whole kit.

Filter by type, search a name. Handovers stay off this public map; they are local-only. This is the kit’s own map, not a diagram of your product. To add a node, change a skill, SOP, or eval and regenerate. Authoring: [Author the Waykit map](/ontology).
