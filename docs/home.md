# Waykit

The public homepage is the Astro landing in `web/` (hero, job picker, proof, demo). This file is the copy source of truth for that story.

Waykit is the software lifecycle for coding agents: grill, spec, TDD, quality, audit, release, plus learning loops. Eval-driven development is one of those loops.

Skills, SOPs, and MCPs are a live graph: you edit the files, `wk ontology check` fails dangling links, kit-knowledge loads one node. Browse it on the [Waykit map](./map.md).
