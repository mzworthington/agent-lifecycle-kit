# Waykit

The public homepage is the Astro landing in `web/` (hero, job picker, CLI table, proof, demo). This file is the copy source of truth for that story.

Waykit is the software lifecycle for coding agents: grill, spec, TDD, quality, audit, release, plus learning loops. You operate it with `wk`. Eval-driven development is one of those loops.

The homepage CLI table is the [Commands](./kit.md#commands) list from the operator guide: measure context, doctor, check, ontology, one MCP profile, audit, eval CI, sync.

Skills, SOPs, and MCPs are a live graph: you edit the files, `wk ontology check` fails dangling links, kit-knowledge loads one node. Browse it on the [Waykit map](./map.md).
