# Copy examples

Use when the brief is vague or you need a register check. Prefer the user's product facts over these sentences.

## Practitioner landing

| Draft / template | Human-centric | Why |
|------------------|---------------|-----|
| *"Ship AI agents you can prove"* | *"Test the tools your agents call"* | Names the job, not a billboard |
| *"Eval-Driven Development · sensible default"* | *"Eval-Driven Development"* | Drops empty authority phrasing |
| *"EDD is the sensible default for tool-using agents"* | *"If an agent can call tools, guessing isn't a test plan."* | Speaks to a peer's worry |
| *"When agents call tools, vibes are not a test strategy."* | Keep the heat, then explain the loop in plain steps | Heat plus how |
| *"KIT MESH · ONLINE"* | *"Kit map"* | Removes cosplay ops chrome |
| *"EDD harness"* plus lab-coat emoji | *"A harness you can run in CI"* | Outcome over badge |
| *"Why EDD?"* / *"Explore EDD →"* | *"How EDD works"* / *"Read the EDD guide →"* | Specific verb |
| *"Blazing-fast deployments"* | *"Deploy in under 90 seconds, no YAML"* or `[METRIC: avg deploy time]` | Fact or flagged gap |
| *"structure, update workflows, and remove files"* | *"structure, update workflows and remove files"* | Drop the serial comma unless the last two items would merge |

## UI / errors

| Draft | Refactored | Why |
|-------|------------|-----|
| *"An error occurred while attempting to parse the payload."* | *"We couldn't process your request. Check your input formatting and try again."* | Plain language plus action |
| *"Click here to confirm subscription parameters."* | *"Confirm subscription"* | Verb-first CTA |
| *"Failure: User account creation failed due to duplicate email address entry."* | *"An account with this email already exists. Sign in or reset your password."* | Recovery path |
| *"The file was uploaded by you"* | *"You uploaded the file"* | Active voice |
| *"Are you sure?"* | *"Delete workspace? This cannot be undone."* | Names the consequence |
