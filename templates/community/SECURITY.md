# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for reports that include exploit details or secrets.

Use GitHub **Private vulnerability reporting** on this repo when enabled, or contact the maintainer for [{{REPO}}](https://github.com/{{REPO}}).

Include:

- A short description and impact
- Steps to reproduce or a proof of concept
- Affected commit, tag, or release

## Supported versions

Security fixes apply to `main` and the latest release.
