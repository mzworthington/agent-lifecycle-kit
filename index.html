Eval-Driven Development is the default

When agents call tools, vibes are not a test strategy. Write a failing eval for the intent you care about, green the tool contract and prompt, refine until routing holds under CI—and feed production misses straight back into the suite.

Red JSONL intent + YAML metrics (tool, schema, judge).
Green Register MCP schemas and minimal instructions; run until green.
Refactor Tighten prompts; gate merges at 95% routing accuracy.

Try it

zsh — kit EDD
# Offline scripted driver — no API key required
$ kit eval run --suite evals/edd/architecture_routing.yaml --model scripted

# CI gate — fail if routing accuracy < 95%
$ kit eval ci --threshold-routing 95 --out out/reports

# Markdown failure traces for PRs
$ kit eval report --format md --out out/reports
