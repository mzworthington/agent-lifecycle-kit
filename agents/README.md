# Host agent stubs

Generated thin Cursor and Claude agent files. Playbooks stay in [`skills/agent-*/SKILL.md`](../skills/). Regenerate with:

```bash
wk agents generate
```

Do not paste SOP or philosophy text here. `wk verify` fails if a stub grows into a playbook.

Install into `~/.cursor/agents` is a later iteration. This tree lives in the kit clone only.

Allowlist: [`skills/subagents.yaml`](../skills/subagents.yaml). Human copy: [docs/subagents.md](../docs/subagents.md).
