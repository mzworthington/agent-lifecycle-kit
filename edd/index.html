Eval-Driven Development

TDD for tool-using agents. Treat prompts and MCP schemas as evaluated contracts— not informal vibes.

Read the guide Browse suites Why EDD?

Context isolation

Every case starts with a fresh context window—no conversational cross-contamination between tests.

Deterministic mocks

Stub tool payloads so you measure model routing and extraction, not third-party network latency.

Dual-layer asserts

Strict JSON schema match plus optional LLM-as-a-judge for unstructured synthesis and hallucination.

CI + prod loop

Threshold gates on PRs; production misses become JSONL cases; shadow judges sample live traffic.

kit eval — EDD harness
# Red → green → refactor against a suite
$ kit eval run --suite evals/edd/architecture_routing.yaml --model scripted

# Block merges when routing accuracy drops below 95%
$ kit eval ci --threshold-routing 95 --out out/reports

# Markdown failure traces for PRs
$ kit eval report --format md --out out/reports
